# 🍎 Apple Mac UI Clone

A frontend practice project recreating the look and structure of Apple's Mac product page using HTML and CSS.

## ✨ Highlights

- Apple-inspired navigation and product sections
- Mac product cards and promotional sections
- Responsive layout practice
- External product imagery and Font Awesome icons

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome

## ▶️ Run locally

Open `index.html` in a browser or use VS Code Live Server.

## 🎯 Purpose

This project is a frontend learning exercise focused on layout, typography, spacing, navigation and product-card UI implementation.

> This is an educational recreation and is not an official Apple website.
